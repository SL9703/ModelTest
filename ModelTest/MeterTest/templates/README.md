# MeterTest 测试结果 Excel 模板

`MeterTestResultTemplate.xlsx` 是测试结果导出的默认模板。现场可以修改标题、标签文字、字体、颜色、列宽及数据行样式，程序会保留这些格式。

模板文件本身可由管理员维护；程序生成的结果工作簿会自动保护全部工作表，操作员可以查看和复制，但不能修改单元格数据、格式或行列结构。

## 固定结构

- 工作表名称必须保留为 `任务信息`、`工位汇总`、`测试明细`。
- `任务信息` 的变量位置固定为 `B2:B9`。
- `工位汇总` 和 `测试明细` 的第 1 行是表头，第 2 行是程序复制的数据行样式。
- 可以修改第 2 行的字体、边框、填充、对齐和数字格式，但不要删除第 2 行。

## 任务变量

| 单元格 | 变量 |
| --- | --- |
| B2 | TaskId |
| B3 | RunId |
| B4 | SchemeName |
| B5 | StartedAt |
| B6 | EndedAt |
| B7 | Status |
| B8 | SaveMode |
| B9 | ResultSummary |

程序导出时会覆盖这些变量值，并从第 2 行开始写入工位汇总和测试明细。
