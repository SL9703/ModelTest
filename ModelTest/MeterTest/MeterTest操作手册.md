# MeterTest 自动测试系统操作手册

## 1. 使用前注意事项

### 1.1 工位数量

MeterTest 默认支持 1-48 号工位。

工位的 485 通信 IP 和端口来自：

```text
MeterTest/config/MeterTestStationConfig.xml
```

文件中的 `485-1通信通道` 和 `485-2通信通道` 都按 1-48 号工位维护 IP/Port。已有的现场配置不会被覆盖；如果某个通道缺少工位节点，程序启动时只会补齐缺失工位。

### 1.2 单相、三相不能混合测试

一次点击“执行测试”时，所选工位必须属于同一种台体模式：

- 单相直接式
- 三相三线直接式
- 三相三线互感式
- 三相四线直接式
- 三相四线互感式

以下情况不能放在同一批次执行：

- 单相和三相混选。
- 三相直接式和三相互感式混选。
- 不同测量接线方式混选。

混合选择会导致台体切换、源输出和测试参数不一致，程序会在执行前提示并停止本轮测试。请先在“资产信息”中确认所选工位的“电表类型”和“接入方式”一致。

### 1.3 电源安全

- “检测单元短路检测”执行前必须确认线路无电压。
- 执行短路检测前，必须确认单相或三相电压已经降为零。
- 测试过程中不要手动拔插控制 PCB、串口服务器或源控制串口。
- 测试结束后先等待系统完成降源，再进行接线或更换电表。

## 2. 系统界面

MeterTest 主要由以下区域组成：

1. **操作区**：执行测试、停止测试、测试方案、资产信息、测试结果。
2. **方案区域**：显示方案、测试项和测试小项。
3. **测试过程区域**：显示工位、测试内容、表位地址、结果和时间。
4. **台体信息采集区域**：显示标准表实时采样的电压、电流、有功、无功、视在功率和功率因数。
5. **测试日志区域**：显示当前选中工位的详细测试过程。
6. **倒计时区域**：显示日计时、起动、潜动及其他统一等待过程的倒计时。

## 3. 资产信息维护

### 3.1 打开资产信息

点击顶部的“资产信息”按钮，进入资产信息维护界面。

资产信息界面显示 1-48 号工位。每行对应一个工位，主要字段如下：

| 字段 | 用途 | 是否参与测试 |
| --- | --- | --- |
| 工位 | 工位编号，1-48 | 是 |
| IP | 工位 485 通信地址 | 是 |
| Port | 工位 485 通信端口 | 是 |
| 条形码 | 扫码枪输入的电表条形码 | 是 |
| 电表地址 | 由条形码规则自动提取，也可检查 | 是 |
| 波特率 | 电表通信波特率，例如 `9600-8-E-1` | 是 |
| 电表类型 | 单相、三相三线、三相四线 | 是 |
| 接入方式 | 直接式、互感式 | 是 |
| 额定电压 | 例如 `220V`、`3×220/380V` | 是 |
| 基本电流 | 例如 `5A`、`1.5A` | 是 |
| 电流规格 | 用于解析 Imin、Itr、Imax | 是 |
| 有功等级 | A、B、C、D 等 | 是 |
| 有功常数 | 被测表有功脉冲常数 | 是 |
| 无功等级 | 例如 `2.0`、`1S`、`0.5S` | 无功测试时使用 |
| 无功常数 | 被测表无功脉冲常数 | 无功测试时使用 |

### 3.2 扫描条形码的位置

1. 点击“资产信息”。
2. 找到需要维护的工位行。
3. 点击该行的“条形码”单元格。
4. 使用扫码枪扫描电表条形码。
5. 扫描内容会写入当前工位的“条形码”列。
6. 程序根据当前条形码规则自动计算“电表地址”。
7. 检查电表地址是否为正确的 12 位地址。
8. 点击“保存”保存当前资产信息。

扫码枪应当直接输入到当前选中的“条形码”单元格，不要把焦点放在“电表地址”列或其他输入框中。

### 3.3 条形码规则1：单区间截取

规则1适合电表地址连续出现在条形码中的情况。

默认配置：

```text
条码起始位：9
截取长度：12
```

程序内部使用从 `0` 开始的下标。因此：

```text
起始下标 = 9
截取长度 = 12
实际截取下标 = 9 到 20
```

示例：

```text
条形码：4130001099990000325151
截取结果：999000032515
```

规则1在资产信息界面显示为：

- `条码起始位`
- `截取长度`

修改后离开输入框，程序会保存规则，并重新计算已经录入条形码的电表地址。

### 3.4 条形码规则2：双区间拼接

规则2适合电表地址被分成两段存放在条形码中的情况。

默认配置为：

```text
段1起始：6
段1长度：2
段2起始：10
段2长度：10
```

程序先截取第一段，再截取第二段，最后直接拼接：

```text
电表地址 = 条形码[段1起始 ... 段1长度] + 条形码[段2起始 ... 段2长度]
```

规则2的四个参数都可以在资产信息界面修改。规则2输入框含义为：

- `段1起始`
- `段1长度`
- `段2起始`
- `段2长度`

规则1和规则2互不冲突，用户通过“条形码规则”下拉框选择当前使用的规则。

### 3.5 条形码地址检查

国网 698 报文的电表地址通常为 12 位十六进制或数字文本。扫描后必须检查：

- 地址不是空值。
- 地址长度为 12 位。
- 地址没有多余空格或分隔符。
- 地址与实际电表铭牌或资产档案一致。

如果截取长度不正确，工位不会被加入测试方案区域，也不能参与执行测试。此时请回到“资产信息”检查条形码、规则和截取结果。

### 3.6 资产信息保存

完成多个工位维护后，点击“保存”：

1. 保存条形码和自动提取的电表地址。
2. 保存电表类型、接入方式、电压、电流和常数。
3. 保存波特率和其他测试参数。
4. 将数据写入本地数据库。

“批量修改”只用于批量覆盖通用资产参数。条形码和电表地址属于每块电表的唯一信息，不应使用批量修改覆盖。

## 4. 资产参数填写建议

### 4.1 电表类型

按铭牌和接线方式选择：

- `单相`
- `三相三线`
- `三相四线`

不要仅根据工位编号判断电表类型。

### 4.2 接入方式

选择：

- `直接式`
- `互感式`

接入方式会影响启动电流、基本误差电流点、无功误差区间和源输出参数。

### 4.3 电流规格

电流规格格式为：

```text
Imin-Itr(Imax)A
```

例如：

```text
0.25-0.5(60)A
```

表示：

```text
Imin = 0.25A
Itr  = 0.5A
Imax = 60A
```

常用直接式规格：

- `0.25-0.5(60)A`
- `0.25-0.5(100)A`
- `0.2-0.5(60)A`
- `0.2-0.5(100)A`
- `0.5-1(60)A`
- `0.5-1(100)A`

常用互感式规格：

- `0.015-0.075(6)A`
- `0.003-0.015(6)A`

选择电流规格后，基本误差测试中的测试点会自动换算：

| 测试点 | 使用值 |
| --- | --- |
| `Imin` | 电流规格中的最小电流 |
| `Itr` | 电流规格中的转折电流 |
| `10Itr` | 转折电流乘 10 |
| `0.5Imax` | 最大电流乘 0.5 |
| `Imax` | 电流规格中的最大电流 |
| `1.2Imax` | 最大电流乘 1.2 |

### 4.4 波特率

资产信息中的波特率是该工位电表的目标通信参数。当前支持：

- `9600-8-E-1`
- `1200-8-E-1`
- `2400-8-E-1`
- `4800-8-E-1`
- `115200-8-E-1`

通信测试会先按资产信息中的默认波特率读取地址。读取失败时，程序会按候选波特率继续尝试；某个波特率读取到正确地址后，停止该工位的后续波特率尝试。

## 5. 选择测试方案

### 5.1 进入测试方案

点击“测试方案”按钮。

左侧方案区域显示：

```text
方案
  测试项
    测试小项
```

右侧测试过程区域显示当前可以参与测试的工位。只有已经扫码并成功生成电表地址的工位才会显示在测试方案区域。

### 5.2 单相方案和三相方案

方案区域顶部可以选择：

- `单相方案`
- `三相方案`

选择方案后，程序重新加载对应 XML：

```text
MeterTestPlanConfig.SinglePhase.xml
MeterTestPlanConfig.xml
```

单相方案不显示三相 ABC 分相基本误差点，也不会执行三相分相测试。三相方案才显示三相相关测试点和无功测试内容。

如果当前资产信息是三相电表，应选择三相方案；如果当前资产信息是单相电表，应选择单相方案。

### 5.3 测试方案中的工位选择

测试过程区域提供：

- `多工位选取`
- `单工位选取`
- `全选`
- `清空`
- `降源`
- `数据保存`

多工位模式可以同时选择多个工位。单工位模式只允许选择一个工位。

注意：未扫码、地址为空或地址格式不完整的工位不会进入测试方案区域，也不能被选择。

## 6. 执行测试

### 6.1 执行前检查清单

点击“执行测试”前逐项检查：

1. 已选择正确的单相或三相方案。
2. 所有待测工位都已扫码。
3. 所有待测工位的电表地址正确且为 12 位。
4. 所选工位的电表类型一致。
5. 所选工位的接入方式一致。
6. 额定电压、基本电流和电流规格正确。
7. 有功等级和有功常数正确。
8. 需要做无功测试时，无功等级和无功常数正确。
9. 485 IP/Port、控制 PCB 和源配置已经连接。
10. 线路状态符合当前测试项目要求。

### 6.2 执行前置流程

点击“执行测试”后，程序通常按以下顺序准备：

1. 检查选中的工位。
2. 检查单相/三相和接入方式是否混用。
3. 建立或复用控制 PCB 长连接。
4. 建立或复用工位 485 TCP 长连接。
5. 根据资产信息执行台体类型切换。
6. 打开源控制串口。
7. 初始化源和电表参数。
8. 对需要升源的测试执行升源。
9. 每 3 秒读取一次标准表，最多等待 20 秒判断电压、电流是否达到目标。
10. 按方案树顺序执行测试小项。

同一个 IP/Port 的 TCP 连接会复用，不会因为不同测试小项重复建立连接。

### 6.3 方案执行顺序

方案从上到下执行。常见顺序为：

1. 设备自检测试。
2. 通信测试。
3. 蓝牙接口检测。
4. 日计时。
5. 起动试验。
6. 潜动试验。
7. 基本误差测试。
8. 常数试验。

实际执行内容以当前方案 XML 中 `enabled="true"` 的测试小项为准。

### 6.4 停止测试

测试过程中点击“停止测试”：

1. 取消当前测试任务。
2. 停止后续测试小项。
3. 尝试执行降源。
4. 清理本轮通信缓存和运行状态。
5. 在日志中记录停止和降源结果。

降源失败不会阻塞界面，也不会弹出连续错误窗口；具体失败原因写入日志。

## 7. 主要测试项目说明

### 7.1 设备自检测试

设备自检通常包括：

- 检测单元短路检测：`0x86`
- 检测单元断路检测：`0x84`
- 温湿度检测：`0xCA`

短路检测前会弹出红色安全确认框。必须确认线路无电压、单相或三相电压已经降下后才能继续。

### 7.2 通信测试

通信测试主要流程：

1. 连接工位 485 通道。
2. 读取或同步串口服务器端口参数。
3. 校验工位目标波特率。
4. 使用当前波特率发送 698 地址读取报文。
5. 去除 `FE FE FE FE` 前导符。
6. 按 698 帧长度截取完整报文。
7. 校验起始符、长度、HCS、APDU、FCS 和结束符。
8. 校验响应中的 OAD 是否为 `40010200`。
9. 提取 6 字节电表地址并与资产地址比较。
10. 输出合格或不合格结论。
11. 当前波特率读取失败时，按候选波特率继续尝试。

通信测试-2与通信测试使用相同流程，但从方案配置选择不同的 485 通道。

### 7.3 日计时

日计时按照方案配置执行：

1. 向控制 PCB 发送日计时开始。
2. 等待配置的测试时间和次数。
3. 发送结果获取。
4. 解析多次误差。
5. 计算平均误差。
6. 根据方案配置的判定规则得出结论。

### 7.4 起动试验

起动试验包括：

1. 按接入方式、有功等级和基本电流计算 `Ist`。
2. 按 `Ist` 升源并读取标准表确认。
3. 设置标准表常数和电能表常数。
4. 发送 `0x38 + 0x00` 开始试验。
5. 按起动时间计算结果等待。
6. 发送 `0x38 + 0xAA` 读取误差。
7. 根据有功等级、电流区间和功率因数计算判定区间。
8. 用实测误差与判定区间比较。

### 7.5 潜动试验

潜动试验包括：

1. 按额定电压的 1.1 倍升源。
2. 发送 `0x25 + 0x01` 开始潜动试验。
3. 按方案配置等待时间。
4. 发送 `0x25 + 0xAA` 获取脉冲数量。
5. 脉冲数为 0 或 1 时合格，大于 1 时不合格。

### 7.6 基本误差

基本误差测试点由方案 XML 配置，测试点中的电流标识会按照资产信息的电流规格自动计算。

例如：

```text
正有-H-1.0-1U-Imin
正有-H-0.5L-1U-Itr
反有-H-0.8C-1U-Imax
```

每个测试点通常执行：

1. 按方向、相别、功率因数和电流点计算升源参数。
2. 升源后读取标准表确认电压、电流。
3. 设置标准表和电能表常数。
4. 发送 `0x38 + 0x00`。
5. 等待理论时间加冗余时间。
6. 发送 `0x38 + 0xAA` 读取结果。
7. 两次结果都读取完成后计算平均误差。
8. 用平均误差与规程允许区间的 60% 判定区间比较。

三相三线电表不显示 B 相测试点；三相四线电表显示 A、B、C 分相测试点；单相方案不显示 ABC 分相测试点。

## 8. 测试结果和数据保存

### 8.1 测试结果

点击“测试结果”可以查看数据库中保存的测试任务。

一条测试任务可以包含多个工位，结果中会保存：

- 工位和电表地址。
- 电表类型和接入方式。
- 电压、基本电流、电流规格。
- 有功等级、无功等级。
- 有功常数、无功常数。
- 起动试验结果。
- 潜动试验结果。
- 日计时各轮结果和平均值。
- 基本误差各测试点、两次结果和平均值。
- 常数试验开始电量、结束电量、走字脉冲和最终误差。

### 8.2 自动保存

只有方案中最后一个测试项全部执行结束后，程序才会询问是否保存本次测试结果：

- 选择“是”：保存全部测试项和全部工位结果。
- 选择“否”：本轮结果不写入测试结果任务。

保存完成后，方案树状态灯恢复为灰色，等待下一轮测试。

### 8.3 手动保存

在测试过程区域点击“数据保存”，可以手动保存当前方案已经产生的结果。适用于测试中断、
部分测试完成或需要先保存当前数据的情况。

## 9. 日志位置

按工位保存的测试日志位于：

```text
XCKJ_logs/TextLog/年/月份/日期/
```

例如：

```text
XCKJ_logs/TextLog/26/08/11/通信测试工位1.log
XCKJ_logs/TextLog/26/08/11/基本误差-正向有功工位1.log
XCKJ_logs/TextLog/26/08/11/日计时工位1.log
```

同一个 `TestItem` 下的全部测试小项和内部步骤写入同一个日志文件，不会按每个 `TestSubItem`
拆成多个文件。

日志通常包含：

- 连接准备、连接成功或失败。
- 完整发送 HEX 报文。
- 完整接收 HEX 报文。
- 协议解析和校验结果。
- 标准表采样值。
- 测试参数和计算过程。
- 倒计时开始和结束。
- 最终结论及失败原因。

## 10. 常见问题处理

### 10.1 测试方案中没有工位

检查以下内容：

1. 是否已经在“资产信息”的“条形码”列扫码。
2. 条形码是否成功生成 12 位电表地址。
3. 是否点击“保存”。
4. 是否当前方案与电表类型匹配。
5. 是否选中了正确的测试方案。

### 10.2 提示不能选择工位

通常是该工位条形码为空、电表地址为空或地址截取结果不完整。请先回到资产信息检查条形码规则。

### 10.3 单相和三相混合

不要直接点击执行测试。先取消不一致工位的选择，或者在资产信息中统一维护同一批次的电表类型和接入方式。

### 10.4 三相误差点没有显示

请确认：

1. 当前选择的是“三相方案”。
2. 资产信息中已经扫码并保存。
3. 电表类型填写为“三相三线”或“三相四线”。
4. 对应测试项在 XML 中 `enabled="true"`。

三相三线不显示 B 相测试点是正常行为；三相四线应显示 A、B、C 分相测试点。

### 10.5 读取到错误的电表地址

1. 检查当前条形码规则。
2. 规则1检查起始位和截取长度。
3. 规则2检查两段起始位置和长度。
4. 删除错误地址后重新扫码。
5. 保存资产信息后重新进入测试方案。

测试方案中的地址读取结果只用于本次通信测试显示和判定，不会反向覆盖资产信息中的电表地址。

## 11. 配置文件位置

MeterTest 主要配置文件：

```text
MeterTest/config/MeterTestPlanConfig.xml
MeterTest/config/MeterTestPlanConfig.SinglePhase.xml
MeterTest/config/MeterTestStationConfig.xml
```

其中：

- `MeterTestPlanConfig.xml`：三相测试方案。
- `MeterTestPlanConfig.SinglePhase.xml`：单相测试方案。
- `MeterTestStationConfig.xml`：工位通信、控制 PCB、源、台体切换、蓝牙和灯光配置。

现场修改配置时，建议先备份 XML。程序只会在缺少节点时创建模板，不应覆盖已经填写的现场 IP、Port
和工位映射。
