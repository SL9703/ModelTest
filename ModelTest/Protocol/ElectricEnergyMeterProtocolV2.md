# 电表测试单元通信协议 V2.0

## 协议组成

台体通信协议包括控制协议和透传协议。

控制协议用于控制台体模块的电源系统、遥信状态设置、遥控状态读取、电压电流等参数检测。

透传协议用于透传模块和终端、模块与虚拟表之间的通信报文或抄表报文，例如 645、698、376.2、376.3 等。

## 通信参数

控制协议采用 RS485 通信：

- 波特率：115200 B/S
- 校验：无校验
- 停止位：1 位

透传协议通信端口参数根据被测模块不同而不同。

## 报文格式

| 字段 | 长度 | 说明 |
| --- | --- | --- |
| 起始字符 | 2 字节 | 固定 `55 44` |
| 数据长度 | 2 字节 | 小端格式，表示从“数据长度”到“校验和”的长度，不包含起始字符和结束字符 |
| 数据方向 | 1 字节 | 下行到 MCU 为 `00`，上行到 PC 为 `01` |
| 地址/通道 | 1 字节 | 印制板地址，有效范围 `01`~`FE`，`FF` 为广播地址，广播命令不回复 |
| 协议类型 | 1 字节 | bit0 表示控制/透传，bit1~bit7 表示设备类型 |
| 命令码 | 1 字节 | 控制协议表示命令，透传协议表示软件透传通道 |
| 数据项 | N 字节 | 控制协议为命令附加数据，透传协议为透传数据 |
| 校验和 | 1 字节 | 从“数据长度”到“校验和前一个字节”的累加和低字节 |
| 结束字符 | 2 字节 | 固定 `AA BB` |

最小无数据项报文的数据长度为：

```text
数据长度2 + 数据方向1 + 地址1 + 协议类型1 + 命令码1 + 校验和1 = 7
```

当前电表 V2 控件为了兼容 V1 功能，未携带业务参数的命令会发送 1 字节数据项 `00`。

## 协议类型

协议类型字段按 bit 解释：

- bit0：`0` 表示控制协议，`1` 表示透传协议
- bit1~bit7：设备类型

设备类型：

| 值 | 设备 |
| --- | --- |
| `01` | 电表 |
| `02` | 终端 |
| `03` | 源 |
| `04` | 仓储 |
| 其他 | 预留 |

协议类型组装公式：

```text
协议类型 = (设备类型 << 1) | 是否透传
```

常用协议类型：

| 协议类型 | 说明 |
| --- | --- |
| `02` | 电表控制协议 |
| `03` | 电表透传协议 |
| `04` | 终端控制协议 |
| `05` | 终端透传协议 |

注意：电表 V2 控件发送控制命令时协议类型固定为 `02`，不能沿用 V1 的 `00`。

## 校验和

校验和为各字节累加和的低字节。

校验范围包括：

```text
数据长度字段低字节
数据长度字段高字节
数据方向
地址
协议类型
命令码
数据项
```

不包含起始字符、校验和自身、结束字符。

## 当前控件命令

`ElectricEnergyMeterControlV2` 的 UI 与 `ElectricEnergyMeterControlV1` 保持一致，业务命令沿用 V1 电表测试功能，外层帧格式改为 V2。

### 测试表位通信命令 0x00

命令码：`00`

发送数据项：1 字节，固定 `00`。

用途：测试表位通信是否正常。

发送示例，地址 `01`：

```text
55 44 08 00 00 01 02 00 00 0B AA BB
```

### 交流电压控制命令 0x01

命令码：`01`

发送数据项：1 字节

| 值 | 说明 |
| --- | --- |
| `01` | A 相上电 |
| `02` | B 相上电 |
| `03` | C 相上电 |
| `04` | ABC 三相上电 |
| `05` | A 相断电 |
| `06` | B 相断电 |
| `07` | C 相断电 |
| `08` | ABC 三相断电 |

说明：当前控件只允许单相或三相全选，不支持两相组合。

### 交流电流控制命令 0x02

命令码：`02`

发送数据项：1 字节

| 值 | 说明 |
| --- | --- |
| `01` | A 相通电流 |
| `02` | B 相通电流 |
| `03` | C 相通电流 |
| `04` | ABC 三相通电流 |
| `05` | A 相断电流 |
| `06` | B 相断电流 |
| `07` | C 相断电流 |
| `08` | ABC 三相断电流 |

说明：当前控件只允许单相或三相全选，不支持两相组合。

### 日计时命令 0x36

命令码：`36`

发送数据项：3 字节

| 字节 | 说明 |
| --- | --- |
| 字节1 | 操作：`00` 开始，`AA` 获取结果，`FF` 停止 |
| 字节2 | 试验时间，单位秒，当前控件限制 `1`~`99` |
| 字节3 | 试验次数，当前控件限制 `1`~`10` |

结果应答中，字节1~3 同请求；如果后续带结果数据，每组结果为 4 字节 float 小端，单位 s/d。

### 表位有无电表检测命令 0x84

命令码：`84`

发送数据项：1 字节

| 值 | 说明 |
| --- | --- |
| `01` | 开始检测 |
| `AA` | 获取检测结果 |

结果应答数据项为 2 字节：字节1为 `AA`，字节2为结果。

| 结果值 | 说明 |
| --- | --- |
| `00` | 无电表，电流线路可能开路 |
| `01` | 有电表，电流线路正常 |
| `02` | 短接磁保持继电器短路异常 |

### 表位电压短路检测命令 0x86

命令码：`86`

发送数据项：1 字节

| 值 | 说明 |
| --- | --- |
| `01` | 开始检测 |
| `AA` | 获取检测结果 |

结果应答数据项为 2 字节：字节1为 `AA`，字节2为结果。

| 结果值 | 说明 |
| --- | --- |
| `00` | 电压正常 |
| `01` | A 相电压短路 |
| `02` | B 相电压短路 |
| `03` | A、B 与 N 短路 |
| `04` | C 相电压短路 |
| `05` | A、C 与 N 短路 |
| `06` | B、C 与 N 短路 |
| `07` | 三相电压都短路 |

### 电机压接命令 0xC9

命令码：`C9`

发送数据项：1 字节

| 值 | 说明 |
| --- | --- |
| `00` | 压接 |
| `01` | 弹开 |
| `FF` | 电机断电 |

### 反馈命令 0xFB

命令码：`FB`

该命令用于接收电表硬件主动反馈。当前控件会识别并展示反馈报文。

### 复位命令 0xFF

命令码：`FF`

发送数据项：1 字节，固定 `00`。

用途：复位电表板卡。
